- 本公开仓库以经过检查的当前源码快照开始独立提交历史；上游原始历史可从来源仓库查看。本地保留的上游历史分支不被删除，也不把上游标签当作本方发布标签。

## 我们修改了什么

| 改动 | 目的 |
| --- | --- |
| 独立bundle ID、`.hanaagent`数据目录和Electron userData | 与作者版隔离 |
| CLI及开发环境路径、启动与实例锁修复 | 让本地构建和运行可复现 |
| 固定本地管理发行策略，阻断作者shell/artifact更新入口 | 防止被作者发行覆盖；未建立新的线上自动更新服务 |
| 安装、更新、数据checkpoint与失败恢复 | 固定正式应用位置，支持配套数据回退 |
| 按应用树哈希去重的压缩归档 | 不再留下多个可搜索的应用副本 |
| 渠道所有权检查 | 作者实例活跃时阻止我们的渠道适配器接管 |
| 相应回归、贡献规则及发布入口整理 | 支持独立维护 |

未恢复上游已经移除的旧功能，也未实现闭源版本的新增能力。没有无差别迁移新版用户数据的通用工具；较高data epoch不能直接用于450，需先备份并单独转换。

## 已验证与未验证

2026-11-08的本地验证覆盖macOS Apple Silicon：构建、类型检查、既有全量测试、打包后真实模型聊天、文件写入/读取、部分历史记录/附件读取，以及既有飞书/微信渠道连接。独立管理器另用真实签名应用验证归档、解包、更新、回退和新增数据保留。

这些结果不代表所有模型、插件、平台或使用场景均已验证。当前CI以macOS为主；Windows/Linux源码保留，尚不承诺独立发行可用性。尚未发布本方公开安装包，也没有本方Apple Developer签名、公证或线上更新服务。个人迁移数据、密钥、会话和实际备份均不在源码仓库中。

上游锁定依赖的安全更新、图标/素材与第三方许可的进一步审核、其他平台验证仍是后续维护工作。保留[Apache-2.0许可证](../../LICENSE)、上游归属和内置第三方许可；来源信息见 [FORK_BASELINE.md](FORK_BASELINE.md)。
